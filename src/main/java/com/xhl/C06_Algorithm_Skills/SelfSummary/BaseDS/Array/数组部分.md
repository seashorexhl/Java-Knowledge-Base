## 算法要点 思想
    1.双指针 / 滑动窗口：这是处理数组和字符串问题的最强利器。看到“连续子数组/子串”、“最长/最短”，立刻想到滑动窗口。
    2。哈希表统计：利用 HashMap 和 HashSet 解决去重、频次统计、多条件筛选问题。
    3.自定义多级排序：OD必考考点！例如按“频次 + 字典序”排序，或者“分辨率多维度排序”，需要熟练掌握自定义比较器（Comparator）。
    4.前缀和：用于快速计算区间和，结合“同余定理”可以解决很多复杂的子数组求和问题。
