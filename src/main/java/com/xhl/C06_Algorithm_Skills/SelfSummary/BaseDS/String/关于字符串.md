# 字符串部分
    
##  要点
    正则表达式、分割/替换/编码转换等操作，尤其注重边界条件（空输入、超长字符串、特殊字符）
    1.字符串分割与提取：熟练使用 split、substring、indexOf 等API。
    2.正则表达式匹配：例如密码解密、日志解析、敏感字段加密等。
    3.进制转换：IP地址分类识别、协议帧十六进制解析。
    4.边界与细节处理：多余空格清理、大小写转换、空字符串判断。
    

## 常用方法
    1. 基础信息与查找
        length()：返回字符串的长度（字符个数）。
        charAt(int index)：返回指定索引位置的字符。
        indexOf(String str)：返回子串首次出现的索引位置，找不到返回 -1。
        lastIndexOf(String str)：返回子串最后一次出现的索引位置。
        contains(CharSequence s)：判断字符串是否包含指定的子串。
    2. 截取与分割
        substring(int beginIndex, int endIndex)：截取从 beginIndex 到 endIndex（不包含）的子字符串。
        split(String regex)：根据正则表达式将字符串分割成字符串数组。
    3. 替换与清理
        replace(char oldChar, char newChar) / replace(CharSequence target, CharSequence replacement)：替换字符串中的特定字符或子串。
        trim()：去除字符串两端的空白字符（包括空格、\n、\r 等控制符）。
    4.大小写转换
        toLowerCase()：将字符串中的所有字符转换为小写。  
        toUpperCase()：将字符串中的所有字符转换为大写。
    5.. 比较与判断
        equals(Object anObject)：比较两个字符串的内容是否完全相同（区分大小写）。
        equalsIgnoreCase(String anotherString)：比较两个字符串的内容是否相同，忽略大小写。
        startsWith(String prefix) / endsWith(String suffix)：判断字符串是否以指定的前缀/后缀开头或结尾。
        ⚠️ 核心避坑：在 Java 中比较字符串内容绝对不能使用 ==（它比较的是内存地址），必须使用 equals() 方法。

    6. 拼接与格式化
    concat(String str) / + 运算符：将字符串进行拼接。
    String.format(String format, Object... args)：格式化字符串，类似 C 语言的 printf。
    💡 性能优化建议：如果在循环中频繁修改或拼接字符串，不要使用 String，应使用可变的 StringBuilder 或 StringBuffer，以避免创建大量临时对象带来的性能开销。
