##  Java 核心思想 与 代码 模板
    
    ⭐⭐⭐定长 滑动窗口 
        核心思想：
        窗口大小 k 固定不变，右指针每次向右移动一步，左指针也同步向右移动一步，
    同时维护窗口内的状态（如和、最大值、计数等）。
        模板：
    eg1:LeetCode 643 子数组最大平均数
     public double findMaxAverage(int[] nums, int k) {
        if (nums == null || nums.length < k) return 0.0;

        int n = nums.length;
        // 1.初始化第一个窗口
        long windowSum = 0; // 注意：用 long 防止 int 溢出
        for(int i=0;i<n;i++){
            windowSum += nums[i];
        }
        long maxSum = windowSum;
        // 2. 开始滑动
        for (int right = k; right < n; right++) {
            // 进右，出左
            windowSum += nums[right];
            windowSum -= nums[right - k];
            
            // 更新最大和
            maxSum = Math.max(maxSum, windowSum);
        }
        
        // 最后再除以 k，避免浮点数精度丢失
        return (double) maxSum / k;
    }
    ⭐⭐⭐不定长 滑动窗口 
    核心思想：
        右指针不断扩张以探索新元素，当窗口内的状态不满足题目条件时，左指针才开始收缩以恢复合法状态。  
    
    模板：LeetCode 209. 长度最小的子数组
    public int minSubArrayLen(int target, int[] nums) {
        int n = nums.length;
        int left = 0;
        int windowSum = 0;
        int result = Integer.MAX_VALUE; // 求最小长度，初始化为最大值

        for (int right = 0; right < n; right++) {
            // 1. 右指针扩张，元素入窗
            windowSum += nums[right];

            // 2. 当窗口和 >= target 时，说明找到了一个合法窗口
            // 此时尝试收缩左边界，看能否找到更短的合法窗口
            while (windowSum >= target) {
                // 更新最小长度
                result = Math.min(result, right - left + 1);
                // 左指针收缩，元素出窗
                windowSum -= nums[left];
                left++;
            }
        }
        
        // 如果 result 没被更新过，说明没有满足条件的子数组，返回 0
        return result == Integer.MAX_VALUE ? 0 : result;
    }
