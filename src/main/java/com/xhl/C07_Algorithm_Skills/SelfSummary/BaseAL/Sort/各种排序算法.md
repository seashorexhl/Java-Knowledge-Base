# 一、常用的排序
   1. 基础排序、高级排序和非比较排序
      
##
    1.冒泡排序 (Bubble Sort)
    核心思想：相邻元素两两比较，将较大的元素像气泡一样“浮”到数组末尾。每一轮确定一个最大值。

    2.选择排序 (Selection Sort)
    核心思想：每次从未排序区间选出最小（或最大）的元素，放到已排序区间的末尾。

    3.插入排序 (Insertion Sort)
    核心思想：类似打扑克牌摸牌，将未排序元素插入到已排序序列的合适位置。在小规模数据或基本有序的数据上表现极佳。
    
    4.快速排序 (Quick Sort) ⭐️
    核心思想：分治法。选一个基准（Pivot），将数组分为两部分：比基准小的放左边，比基准大的放右边，然后递归处理左右两部分。
    
    5.归并排序 (Merge Sort) ⭐️
    核心思想：分治法。将数组不断二分，直到子数组长度为 1，然后将有序的子数组合并成一个大的有序数组。
    
    6.堆排序 (Heap Sort)
    核心思想：利用最大堆的性质，堆顶永远是最大值。将堆顶与末尾交换，缩小堆的范围，然后对堆顶进行下沉调整（Heapify），重复此过程。

    7.Java 官方底层实现 (Arrays.sort())：
    基本数据类型 (int[])：使用 双轴快速排序 (Dual-Pivot Quicksort)，因为基本类型不需要稳定性，快排常数项更小。
    对象数组 (Object[])：使用 TimSort（归并排序 + 插入排序的优化版），保证稳定性且对部分有序数据极快。
    
    💡 总结与实战建议
    | 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 | 适用场景 |
    | 冒泡/选择 |  $ O(n^2) $  |  $ O(n^2) $  |  $ O(1) $  | 冒泡稳定 | 教学、极小数据量 |
    | 插入排序 |  $ O(n^2) $  |  $ O(n^2) $  |  $ O(1) $  | 稳定 | 数据基本有序、小数据量 |
    | 快速排序 |  $ O(n \log n) $  |  $ O(n^2) $  |  $ O(\log n) $  | 不稳定 | 通用场景首选，缓存友好 |
    | 归并排序 |  $ O(n \log n) $  |  $ O(n \log n) $  |  $ O(n) $  | 稳定 | 链表排序、外部排序、要求稳定 |
    | 堆排序 |  $ O(n \log n) $  |  $ O(n \log n) $  |  $ O(1) $  | 不稳定 | 内存受限、求 Top K 问题 |
