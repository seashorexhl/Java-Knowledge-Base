# 常用算法 思想 和 代码 总结 ⭐⭐⭐⭐⭐

    争取 内化于心 外化于 代码 活学活用  
    滑动窗口 : 维护一个窗口，通过移动左右边界来寻找满足条件的最优解。
    单调栈 : 栈内元素保持单调递增或递减。用于快速找到“下一个更大/更小元素”。
    双指针 : 使用两个指针在数组/链表上同向或相向移动，通常能将 O(N²) 的暴力解法优化到 O(N)。
    动态规划 : 将大问题拆解为小问题，通过记录小问题的解（状态）来避免重复计算。
    回溯 : DFS 的一种，用于在解空间树中搜索所有可能的解。核心是“做选择”和“撤销选择”。
    二分查找 : 在有序数组中，通过不断缩小搜索范围来快速定位目标值。
    BFS: 一层一层地遍历图或树，常用于求最短路径或层级遍历。
    DFS: 一条路走到黑，不撞南墙不回头。常用于遍历所有可能、连通性问题。
    分治: 将一个难以直接解决的大问题，分割成一些规模较小的相同子问题，以便各个击破。
        通常包含三个步骤：分解 (Divide)、解决 (Conquer)、合并 (Combine)。
    贪心: 在每一步选择中都采取在当前状态下最好或最优（即最有利）的选择，从而希望导致结果是全局最好或
        最优的算法。注意：贪心没有固定的代码模板，它的核心在于“证明局部最优能推导出全局最优”。
    拓扑排序: 解决有向无环图（DAG）中的依赖关系和执行顺序问题。通常结合 BFS（Kahn算法）使用，
        核心是维护一个“入度为0”的节点队列。
    并查集: 极其高效地处理动态连通性问题。核心操作只有两个：find（找根节点）和 union（合并两个集合）。
    优先队列/堆: 动态维护一个集合，并能在O(logN) 的时间内获取最大值或最小值。
    字典树：一种多叉树，利用字符串的公共前缀来减少查询时间。
    前缀和： 预处理一个数组 preSum，其中 preSum[i] 表示原数组前 i 个元素的总和。这样，任意区间 [left, right] 的和就可以通过 preSum[right+1] - preSum[left] 在O(1) 时间内求出。
    状态压缩:  当题目中出现 “N 比较小（通常 N ≤ 20）”，且要求 “分配任务”、“全排列”、“组合最优” 时，用二进制位来表示集合的状态。   
    差分数组: 用于“频繁对区间进行加减操作”。如果每次都用循环去修改区间，复杂度是O(1) ，最后再求一次前缀和还原数组。
    多路归并: 有 K 个有序数组，需要把它们合并成一个有序数组，或者找全局第 K 大/小。核心是用优先队列（堆）来维护 K 个数组的当前最小/最大值。
    模拟与状态机: 理清状态流转，做好防御性编程。

## 滑动窗口（Slide Window）
    
    模板:
    1.变长滑动窗口:
    int left = 0, right = 0;
    while (right < s.length()) {
        // 1. 扩大窗口：处理 right 指向的元素
        window.add(s[right]);
        right++;
        // 2. 收缩窗口：判断是否需要移动 left
        while (window.needShrink()) {
            // 处理 left 指向的元素
            window.remove(s[left]);
            left++;
        }
        // 3. 更新结果
        result = Math.max(result, right - left);
    }
    2.定长 滑动窗口

    int left = 0, right = 0;
    int windowSum = 0;
    int k = 3; // 假设窗口固定长度为3
    
    while (right < nums.length) {
    // 1. 扩大窗口
    windowSum += nums[right];
    right++;
    
        // 2. 当窗口大小达到 k 时，进行处理和收缩
        if (right - left == k) { // 注意这里是 if，不是 while
            // 更新结果，例如记录最大和
            result = Math.max(result, windowSum);
            
            // 收缩窗口，为下一轮移动做准备
            windowSum -= nums[left];
            left++;
        }
    }
    
## 单调栈（Monotonic Stack）

    模板：
    Stack<Integer> stack = new Stack<>();
    // 通常倒序遍历，方便找到右侧的“下一个”
    for (int i = n - 1; i >= 0; i--) {
        // 1. 维护单调性：如果栈顶元素不满足条件（如小于等于当前元素），则弹出
        while (!stack.isEmpty() && arr[stack.peek()] <= arr[i]) {
            stack.pop();
        }
        // 2. 此时栈顶就是“下一个更大元素”的索引（如果栈为空则不存在）
        if (!stack.isEmpty()) {
            result[i] = stack.peek(); // 或者 arr[stack.peek()]
        }
        // 3. 将当前元素索引入栈
        stack.push(i);
    }

## 双指针（Two pointers）

    模版：
    int slow = 0, fast = 0;
    while (fast < nums.length) {
        // fast 指针负责探路，寻找满足条件的元素
        if (nums[fast] 满足条件) {
            // 将满足条件的元素“搬运”到 slow 指针的位置
            nums[slow] = nums[fast];
            slow++;
        }
        fast++;
    }
    // slow 的值通常就是新数组的长度
    return slow;

## 二分查找（Binary Search）

    模板：
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2; // 防止溢出
        if (nums[mid] == target) {
            return mid; // 找到目标
        } else if (nums[mid] < target) {
            left = mid + 1; // 目标在右半部分
        } else {
            right = mid - 1; // 目标在左半部分
        }
    }
    return -1; // 未找到
        
## BFS（广度优先遍历 Breadth-First Search） 

    模板：
    Queue<Node> queue = new LinkedList<>();
    Set<Node> visited = new HashSet<>(); // 防止走回头路
    
    queue.offer(startNode);
    visited.add(startNode);
    int steps = 0; // 记录步数或层级
    
    while (!queue.isEmpty()) {
        int size = queue.size(); // 当前层级的节点数量
        for (int i = 0; i < size; i++) {
            Node curr = queue.poll();
            // 1. 处理当前节点：判断是否到达终点
            if (curr == target) return steps;
            // 2. 扩展：将当前节点的所有未访问邻居加入队列
            for (Node neighbor : curr.getNeighbors()) {
                if (!visited.contains(neighbor)) {
                    queue.offer(neighbor);
                    visited.add(neighbor);
                }        
            }
        }
        steps++; // 一层遍历完，步数+1        
    }

## DFS (深度优先 遍历 Depth-First Search)

    模板：
    void dfs(Node node, Set<Node> visited) {
        // 1. 处理当前节点
        // ...
        
        // 2. 标记为已访问
        visited.add(node);
        
        // 3. 递归访问所有邻居
        for (Node neighbor : node.getNeighbors()) {
            if (!visited.contains(neighbor)) {
                dfs(neighbor, visited);
            }
        }
    }

## 回溯（Backtracking） 
    
    模板:
    void backtrack(路径, 选择列表) {
        if (满足结束条件) {
            result.add(路径); return;
        }
        for (选择 : 选择列表) {
            做选择(路径, 选择);
            backtrack(路径, 选择列表);
            撤销选择(路径, 选择); // ⚠️ 最容易忘的一步
        }
    }

## 分治(Divide and Conquer)

    模板:
    ResultType divideAndConquer(Problem problem) {
        // 1. 递归终止条件（最重要的一步，防止无限递归）
        if (problem.size() <= threshold) {
            return solveDirectly(problem);
        }
        
        // 2. 分解：将问题拆分为规模更小的子问题
        List<SubProblem> subProblems = divide(problem);
        
        // 3. 解决：递归处理子问题
        List<ResultType> subResults = new ArrayList<>();
        for (SubProblem sub : subProblems) {
            subResults.add(divideAndConquer(sub));
        }
        
        // 4. 合并：将子问题的结果合并为当前问题的结果
        return merge(subResults);
    }

## 贪心(Greedy)

    模板:
    // 1. 排序：贪心往往需要先对数据进行排序，以方便做出“局部最优”的选择
    Arrays.sort(intervals, (a, b) -> a[1] - b[1]); // 例如按结束时间升序
    
    // 2. 遍历并贪心选择
    int result = 0;
    int lastEnd = 0; // 记录上一个选择的结束状态
    
    for (int[] interval : intervals) {
        // 3. 判断当前选择是否满足贪心条件（不重叠、在范围内等）
        if (interval[0] >= lastEnd) {
            result++;             // 计数或累加
            lastEnd = interval[1]; // 更新状态
        }
    }
    return result;

## 拓扑排序(Topological Sort)

    模板：
    Queue<Integer> queue = new LinkedList<>();
    int[] inDegree = new int[n]; // 1. 统计所有节点的入度
    
    // 2. 将入度为 0 的节点入队
    for (int i = 0; i < n; i++) {
        if (inDegree[i] == 0) queue.offer(i);
    }
    
    List<Integer> result = new ArrayList<>();
    while (!queue.isEmpty()) {
        int curr = queue.poll();
        result.add(curr); // 3. 记录当前节点
    
        // 4. 遍历当前节点的所有邻居，将它们的入度减 1
        for (int neighbor : graph.get(curr)) {
            inDegree[neighbor]--;
            if (inDegree[neighbor] == 0) { // 5. 如果减为0，说明依赖已解除，入队
                queue.offer(neighbor);
            }
        }
    }
    // 6. 如果 result.size() != n，说明图中有环，无法完成拓扑排序
    return result.size() == n ? result : new ArrayList<>();

## 并查集(Union-Find)

    模板:
    int[] parent = new int[n];
    // 1. 初始化：每个节点的父节点是自己
    for (int i = 0; i < n; i++) parent[i] = i;
    
    // 2. 查找根节点（带路径压缩优化，防止退化成链表）
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }
    
    // 3. 合并两个集合
    void union(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        if (rootX != rootY) {
            parent[rootX] = rootY;
        }
    }

## 字典树(Trie)

    模板：
    class TrieNode {
        TrieNode[] children = new TrieNode[26]; // 假设只有小写字母
        boolean isEnd = false; // 标记是否是某个单词的结尾
    }
    
    // 插入单词
    void insert(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) {
                node.children[idx] = new TrieNode();
            }
            node = node.children[idx];
            }
        node.isEnd = true; // ⚠️ 极易忘记：标记单词结束
    }
    // 查找单词是否存在
    boolean search(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) return false;
            node = node.children[idx];
        }
        return node.isEnd; // ⚠️ 极易忘记：必须判断 isEnd，不能只判断前缀    
    }       
       

##  前缀和（Prefix Sum）
    
    模板：
    int n = nums.length;
    // 1. 初始化前缀和数组（通常长度+1，方便处理边界）
    int[] preSum = new int[n + 1];
    
    // 2. 预处理：preSum[i] 表示 nums[0...i-1] 的和
    for (int i = 1; i <= n; i++) {
        preSum[i] = preSum[i - 1] + nums[i - 1];
    }
    
    // 3. 查询：获取闭区间 [left, right] 的和
    // 公式：preSum[right + 1] - preSum[left]
    int getRangeSum(int left, int right) {
        return preSum[right + 1] - preSum[left];
    }

## 前缀和（进阶）
    
    模板：
    // 寻找和为 k 的连续子数组个数
    public int subarraySum(int[] nums, int k) {
        // key: 前缀和, value: 该前缀和出现的次数
        Map<Integer, Integer> map = new HashMap<>();
        // ⚠️ 极易忘记：初始化前缀和为0的情况出现1次（处理从头开始的子数组）
        map.put(0, 1);
    
        int count = 0, preSum = 0;
        for (int num : nums) {
            preSum += num;
            // 如果存在前缀和为 (preSum - k)，说明中间这段区间的和正好是 k
            if (map.containsKey(preSum - k)) {
                count += map.get(preSum - k);
            }
            // 将当前前缀和存入 map
            map.put(preSum, map.getOrDefault(preSum, 0) + 1);
        }
            return count;
    }

## 状态压缩 DP (Bitmask DP) 

    应用场景：处理小规模组合问题
    模板：
    // 1. 状态定义：dp[mask] 表示当前已选任务集合为 mask 时的最优解
    int[] dp = new int[1 << n];
    
    // 2. 遍历所有状态
    for (int mask = 0; mask < (1 << n); mask++) {
    // 3. 尝试在当前集合中加入一个新的任务 i
    for (int i = 0; i < n; i++) {
        if ((mask & (1 << i)) == 0) { // 如果任务 i 还没被选
            int newMask = mask | (1 << i); // 更新状态
            // 4. 状态转移（根据题目逻辑计算代价）
            dp[newMask] = Math.max(dp[newMask], dp[mask] + profit[i]);
            }
        }
    }
    return dp[(1 << n) - 1]; // 返回全选状态的结果

    void increment(int l, int r, int val) {
    diff[l] += val;
    if (r + 1 < n) diff[r + 1] -= val;
    }
    
    // 2. 还原最终数组
    int[] result = new int[n];
    result[0] = diff[0];
    for (int i = 1; i < n; i++) {
    result[i] = result[i - 1] + diff[i];
    }
