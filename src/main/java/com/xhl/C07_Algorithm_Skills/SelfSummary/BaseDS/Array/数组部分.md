    ⭐⭐⭐⭐ 单序列双指针： 
        用于有序数组或链表。利用数组的单调性，设置一左一右两个指针向中间逼近，从而避免双重循环。
    典型场景：两数之和、盛水最多的容器、回文串判断、快慢指针（找环/找中点）。

    public int twoPointersSingle(int[] nums) {
        int left = 0, right = nums.length - 1;
        int result = 0;
        
        while (left < right) {
            int currentVal = nums[left] + nums[right]; // 根据题意计算状态
            
            if (currentVal == target) {
                result = ...; // 找到目标
                break; 
            } else if (currentVal < target) {
                left++;  // 值太小，左指针右移增大值
            } else {
                right--; // 值太大，右指针左移减小值
            }
        }
        return result;
    }
    
    ⭐⭐⭐⭐ 双序列双指针
        用于合并两个有序数组或比较两个序列。两个指针分别指向两个序列的起始位置，每次比较两个指针所指元素，将较小（或较大）的元素处理掉，并移动对应指针。
    典型场景：合并两个有序链表/数组、寻找两个数组的中位数、字符串匹配。

    public void twoPointersDouble(int[] nums1, int[] nums2) {
        int p1 = 0, p2 = 0;
        List<Integer> result = new ArrayList<>();
    
    // 1. 同时遍历两个序列
    while (p1 < nums1.length && p2 < nums2.length) {
        if (nums1[p1] <= nums2[p2]) {
            result.add(nums1[p1]);
            p1++;
        } else {
            result.add(nums2[p2]);
            p2++;
        }
    }
    
        // 2. 处理剩余元素（非常重要，极易漏写）
        while (p1 < nums1.length) result.add(nums1[p1++]);
        while (p2 < nums2.length) result.add(nums2[p2++]);
    }

    ⭐⭐⭐ 三指针思想
        用于原地分区（Partition）问题。最经典的是荷兰国旗问题：将数组分为三个区域（例如：小于 pivot、等于 pivot、大于 pivot）。
    维护三个指针：
        p0 (或 left)：[0, p0) 的区域存放小于目标值的元素。
        p2 (或 right)：(p2, n-1] 的区域存放大于目标值的元素。
        curr (或 mid)：[p0, curr] 是已处理的等于目标值的区域，[curr, p2] 是待处理的未知区域。
    典型场景：颜色分类（LeetCode 75）、移动零（LeetCode 283）、按奇偶排序数组。
    
    public void threePointers(int[] nums) {
        int p0 = 0;             // 指向小于区的下一个位置
        int curr = 0;           // 当前遍历的指针
        int p2 = nums.length - 1; // 指向大于区的前一个位置
    
        while (curr <= p2) {
            if (nums[curr] == 0) { 
                // 遇到小值：与 p0 交换，p0 和 curr 都前进
                swap(nums, curr, p0);
                p0++;
                curr++;
            } else if (nums[curr] == 2) {
                // 遇到大值：与 p2 交换，p2 后退，但 curr 不动（因为换过来的值还没检查）
                swap(nums, curr, p2);
                p2--;
            } else {
                // 遇到中值：直接跳过
                curr++;
            }
        }
    }
    
    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }

    ⭐⭐⭐⭐⭐ 二分查找
        核心思想是分治：在有序的数据结构中，每次将搜索区间缩小一半，从而将时间复杂度从 
    O(N) 降维到O(logN) 。
    public int binarySearch(int[] nums, int target) {
        int left = 0, right = nums.length - 1; // 注意：right 初始化为 length - 1
    
        // 注意：使用 <=，因为当 left == right 时，区间 [left, right] 仍有一个元素需要检查
        while (left <= right) {
            // 注意：防止 (left + right) 溢出，且使用位运算或整除
            int mid = left + (right - left) / 2; 
            
            if (nums[mid] == target) {
                return mid; // 找到目标，直接返回
            } else if (nums[mid] < target) {
                left = mid + 1; // 目标在右半区，因为 mid 已经比较过，所以左边界变为 mid + 1
            } else {
                right = mid - 1; // 目标在左半区，因为 mid 已经比较过，所以右边界变为 mid - 1
            }
        }
    
        return -1; // 未找到目标
    }
