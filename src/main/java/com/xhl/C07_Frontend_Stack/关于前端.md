# 🚀 Java & Frontend Knowledge Base

> 💡 **全栈开发知识体系与实战笔记**

本项目旨在构建一个系统化、结构化的全栈开发知识库。内容涵盖从 Java 后端底层原理、企业级框架，到 Vue 3 前端生态、工程化构建，以及架构设计与个人成长。这里不仅是我的学习笔记，也是我在技术进阶路上的里程碑。

## 📂 目录结构 (Directory Structure)

本项目按照技术深度和学习路径进行了模块化分类：

### 01_Java_Core (Java 核心基础)
> 🧱 万丈高楼平地起，这里是所有技术的基石。
- **EffectiveJava**: 《Effective Java》最佳实践与代码规范笔记。
- **IO**: Java I/O 模型、NIO 网络编程及零拷贝技术。
- **java17**: Java 17+ 新特性探索（Records, Sealed Classes, Pattern Matching）。
- **JVM**: 虚拟机内存模型、GC 算法、类加载机制及调优实战。
- **Multithreading**: JUC 并发包详解、线程池原理、锁机制与高并发实战。

### 02_Architecture_Design (架构与设计)
> 🏛️ 提升代码质量与系统扩展性的内功心法。
- **DesignPattern**: 23 种设计模式的代码实现与应用场景分析。
- **Refactoring**: 代码重构技巧，识别并消除代码坏味道。
- **Reactor**: 响应式编程范式（Project Reactor）与异步非阻塞开发。

### 03_Enterprise_Frameworks (企业级框架)
> 🛠️ 实际工作中构建大型应用的主流技术栈。
- **Spring**: Spring Boot/Cloud 生态源码分析与实战配置。
- **JavaEE**: Servlet/JSP 等传统 Web 规范（理解框架底层原理）。
- **BPMN**: 工作流引擎（Flowable/Activiti）与业务流程建模。

### 04_Middleware_Distributed (中间件与分布式)
> ⚡ 解决高并发、高可用、海量数据处理的核心组件。
- **MQ**: 消息队列（RabbitMQ/Kafka/RocketMQ）原理、集群搭建与消息可靠性保障。
- *(待补充: Redis, Elasticsearch, Dubbo 等...)*

### 05_Algorithm_Skills (算法与技能)
> 🧠 保持逻辑思维敏锐度，应对面试与复杂场景。
- **LeetCode**: 数据结构与算法刷题记录（按题型分类）。

### 06_Career_Growth (职业成长与总结)
> 🌱 技术之外的软实力与职业规划思考。
- **ODExam**: 华为 OD 考试相关准备材料与真题。
- **PersonalAware**: 个人认知提升、职业规划、软技能笔记。
- **SelfSummary**: 阶段性工作总结、技术复盘、年度回顾。

### 07_Frontend_Stack (前端核心技术栈)
> 🎨 现代前端工程化与 Vue 3 生态实践。
- **Vue3_ElementPlus**: 基于 Vue 3 + Element Plus 的中后台系统实战与组件封装。
- **Vite_Ecosystem**: Vite 构建工具、Vue Router、Pinia 状态管理及 VueUse 工具集。
- **CSS_Solutions**: SCSS 主题定制、Tailwind CSS 原子化样式实践。
- **TypeScript**: 前端类型系统、接口定义与泛型高级用法。
- **Testing**: Vitest 单元测试与 Playwright E2E 自动化测试。

- **持续性**：保持更新，跟随技术潮流不断迭代。
