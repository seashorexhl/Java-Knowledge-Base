# 以“银行账户与转账系统”为例 高标准的业务领域模型

    演示Effective 核心、最高频的 15-20 条规则
    1. 核心领域对象：BankAccount
    2. 转账请求对象：TransferRequest
    3. 账户状态枚举：AccountStatus
    4. 业务服务层：TransferService
    5. 工具类与常量：BankUtils
