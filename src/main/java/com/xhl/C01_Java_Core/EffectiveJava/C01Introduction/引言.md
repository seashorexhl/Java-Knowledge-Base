### 1. 创建和销毁对象（条目1-9）

    条目1：用静态工厂方法代替构造器
        静态工厂方法可命名、可缓存实例、可返回子类型，比构造器更灵活23。

    条目2：多参数构造时优先使用生成器（Builder）
        解决构造器参数过多时的可读性问题，避免“伸缩构造器反模式”3。

    条目3：利用私有构造器或枚举类型强化Singleton属性 用枚举实现单例 
        枚举单例是线程安全且防反射攻击的最佳实践，优于私有构造器方案38。

    条目4：利用私有构造器防止类被实例化

    条目5：优先考虑通过依赖注入来连接资源
    
    条目6：避免创建不必要的对象

    条目7：清除过期的对象引用

    条目8：避免使用终结方法和清理方法

    条目9：try-with-resources 优于 try-finally
        自动管理资源关闭，避免资源泄漏，代码更简洁510。
